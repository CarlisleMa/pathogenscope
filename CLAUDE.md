## Project Overview

PathogenScope predicts host-pathogen protein interactions for *Acinetobacter baumannii* drug target discovery. It combines three signals into a composite ranking:

1. **Foldseek structural mimicry** (via Tamarind Bio API) — bacterial proteins that structurally mimic human proteins
2. **FlashPPI intra-pathogen PPI network** (via Modal GPU) — hub proteins within the pathogen
3. **Cross-kingdom FlashPPI predictions** (from collaborator Joe) — direct bacterial↔human PPI predictions

Composite score formula: `mimicry_TM × 0.35 + flashppi_score × 0.35 + hub_degree × 0.30`. Weights auto-adjust when cross-kingdom data is unavailable.

## Pipeline Architecture

Scripts run sequentially and read/write from `results/`:

```
tamarind_alphafold.py  (optional: predict missing structures)
        ↓
[Foldseek run → results/ab_vs_human_raw.tsv]
        ↓
process_mimicry.py  → results/mimicry_hits.csv, results/mimicry_with_partners.csv
        ↓
[FlashPPI on Modal → results/pathogen_ppis.tsv]
        ↓
pathogen_hubs.py    → results/pathogen_network.csv, results/pathogen_hubs.csv
        ↓
merge_signals.py    → results/merged_targets.json
        ↓
export_dashboard.py → results/network_data.json
```

## Key Thresholds and Constants

- Mimicry filter: TM-score ≥ 0.5 AND sequence identity < 30%
- FlashPPI PPI score threshold: ≥ 0.7
- STRING interaction partners: score > 700
- Hub score: `0.6 × normalized_degree + 0.4 × betweenness_centrality`

## Validation Targets (Ground Truth)

OmpA → TLR2/TLR4/fibronectin/DRP1, Ata → collagen IV/fibronectin. Blind rediscovery of these known interactions is the key demo metric.

## External Dependencies

- **Tamarind Bio API** (`https://api.tamarind.bio`): Foldseek jobs and optional AlphaFold predictions. Requires `TAMARIND_API_KEY` env var.
- **UniProt REST API**: Gene name mapping and organism filtering
- **STRING DB API**: Interaction partner lookups (species 9606 = human)
- **FlashPPI** (`FlashPPI/` subdir, cloned from TattaBio): PPI prediction model run on Modal GPUs
- **Foldseek** (`foldseek/bin/foldseek`): Local binary for structural similarity search

## Data Layout

- `data/structures/` — AlphaFold `.cif` structure files (AF-{UniProtID}-F1-model_v4.cif)
- `data/ab_proteome.fasta` — A. baumannii reference proteome (UP000006737)
- `cache/` — JSON caches for UniProt, STRING, and Tamarind job lookups (auto-created)
- `results/` — All pipeline outputs (gitignored, regenerated by scripts)

## Conventions

- All scripts use `ROOT = Path(__file__).resolve().parent.parent` to resolve paths relative to project root
- API responses are cached in `cache/` as JSON to avoid redundant requests
- Column name detection is flexible — scripts handle multiple naming conventions for TSV inputs (e.g., FlashPPI output columns may vary)
- UniProt ID extraction handles multiple formats: `AF-Q6F7T4-F1-model_v4`, `sp|Q6F7T4|OMPA_ACIBU`, plain accession
